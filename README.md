# AI Lab 1 - Introduction to AI & Paradigms

## Files
- `Lab1_Report.docx`: report for Tasks 1-3
- `lab1_compare.py`: compares rule-based and probability-threshold decisions
- `lab1_rules.py`: modified rule-based scholarship checker with exactly four core test cases

## Requirements
- Python 3
- Microsoft Word or a compatible DOCX reader for the report

## Run
```bash
python lab1_compare.py
python lab1_rules.py
```

The thresholds and sample inputs are synthetic lab assumptions. `Review` means human review,
not an automatic scholarship award.
